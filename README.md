# Angular / TypeScript Developer

I build multi-tenant web applications with an agentic workflow in Claude Code — with end-to-end ownership from architecture to production deployment.

## Current Focus

- **Frontend Owner (Enterprise):** Designed and built the complete frontend of a multi-tenant event registration and management platform from scratch, and owned it alone for two years — architecture, permission model, HTTP error handling, i18n, 50+ screens — including production deployments. Angular · PrimeNG · Tailwind.
- **Full-stack + code review (since October 2026):** The team moved to agentic development with Claude Code, and the backend developers now work full-stack too. I work across Java EE and Angular, and remain responsible for the frontend: I review my two backend colleagues' code, handle the merge requests and resolve merge conflicts.
- **Mobile (Capacitor):** Built ~90% of an offline-first Android app for continuous QR scanning at sports events: local storage with scheduled background sync, camera access, and refresh-token auth. Ran on **125 devices to scan runners' laps at an event with 12,000+ registrants**.
- **Product (solo, in production):** Building a multi-tenant SaaS end to end — Angular + NestJS + Prisma + PostgreSQL. HttpOnly JWT with rotating refresh tokens, CSRF origin checks, per-user and per-IP rate limiting, granular permission keys, subscription-based feature gating, scheduled jobs, and CSV/XLSX import with encoding detection. Deployed on Railway + Vercel.

## Methodology

I build reliable, maintainable software in an agentic workflow with Claude Code, following a fixed process rather than working ad hoc: a written spec first, then a plan only — I review and refine the plan before any code is generated. One task at a time, so I can follow what actually changes. No real client data, passwords or secret keys ever reach the agent, and decisions are documented so the context survives.
